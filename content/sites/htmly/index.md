HTMLy is a Brazilian static hosting platform purpose-built for HTML sites generated by AI tools (Claude, ChatGPT, Gemini). Drag and drop a single HTML file or zip archive, pick a custom subdomain, and your site goes live in 30 seconds — no signup required for the first hour.

## Features of HTMLy

HTMLy is optimized for the AI-to-web workflow with simplicity-first features:

- **AI-friendly hosting**: Built specifically for HTML generated by Claude, ChatGPT, Gemini and other LLMs.
- **No signup trial**: Upload anonymously and get a public link valid for 1 hour.
- **Custom subdomain**: Free plan includes `yourname.htmly.com.br`.
- **Custom domain**: Pro plans support your own domain with automatic SSL via Cloudflare.
- **Single file or zip**: Upload a single HTML file or full multi-file site as zip archive.
- **Inline editor**: Edit HTML, CSS, and JS directly in the browser (Pro+).
- **Password protection**: Restrict site access with password (Pro+).
- **PIX payment**: Native Brazilian PIX in BRL .
- **Portuguese support**: 100% Brazilian Portuguese interface and customer support.
- **Server-side analytics**: Privacy-first view counting (no external JavaScript, LGPD compliant).

## Limits on HTMLy

- **Free plan**: 1 site, 10 MB per site, custom subdomain.
- **Starter (R$ 12/mo)**: 5 sites, 50 MB per site.
- **Pro (R$ 29/mo)**: 20 sites, 500 MB per site, custom domain, password protection, inline editor.
- **Agency (R$ 79/mo)**: 100 sites, 2 GB per site, white label, sub-accounts.
